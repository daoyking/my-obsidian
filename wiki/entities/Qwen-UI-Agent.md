# Qwen-UI-Agent

## 是什么

> 阿里巴巴正式推出的 GUI 智能体基座模型，以真实世界为中心，覆盖移动端、电脑端、网页端及深度搜索（DeepSearch）环境。

## 核心特性

- 多平台覆盖：移动端、电脑端、网页端
- 深度搜索能力：DeepSearch 环境支持
- 基座模型定位：可作为智能体开发的底层能力

## 适用场景

- GUI 自动化操作
- 跨平台智能体开发
- 网页/移动端任务自动化
