# GitHub

## 是什么

全球最大的代码托管与协作平台，由 GitHub Inc. 于 2008 年创立，2018 年被微软以 75 亿美元收购。提供 Git 版本控制、代码审查、CI/CD、Issue 跟踪、Pages 托管等核心功能，是开源生态的基础设施。

## 核心功能

- **代码托管**：基于 Git 的分布式版本控制
- **GitHub Actions**：自动化 CI/CD 工作流
- **Pull Request**：代码审查与协作机制
- **GitHub Pages**：静态网站托管
- **GitHub Sponsors**：开源项目资助平台
- **GitHub Security**：漏洞扫描、依赖审查、Secret scanning

## AI 相关动态

- **GitHub Copilot**：AI 编程助手，支持代码补全、对话式编码
- **GitHub SOS Fund**：第四期 50 个开源项目结合 AI 辅助工作流进行安全加固
- **GitHub 智能体**：支持 AI 辅助的代码审查与漏洞发现

## 与大模型生态的关系

- 大量开源模型（Hugging Face、Google、Meta 等）在此发布
- 是 AI Agent 开发（如 Claude Code、Cursor）的重要集成平台
- 提供 GitHub Models API（基于 OpenAI、Anthropic 等模型）
