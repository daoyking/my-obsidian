# Mojo

## 是什么

Mojo🔥 是 Modular 公司开发的编程**语言 + 编译器 + 工具链**，定位是"Python 的超集 + 系统编程能力"。Mojo 于 2026-08-12 发布 1.0 版本（源码稳定），**2026-08-19 正式开源**，采用 Apache 2.0 许可证（含 LLVM 例外）。

## 核心特性

- **Python 兼容**：可直接运行 Python 代码，无缝迁移
- **系统编程能力**：通过 Mojo 原生语法访问内存、控制指针、编写高性能内核
- **编译器 + 工具链全开源**：2026-08-19 开源包含整个编译器、工具链及全部源码（此前仅开放标准库社区贡献）
- **Apache 2.0 + LLVM 例外**：允许商业使用，且 LLVM 生态兼容

## 开源时间线

- 2024 年起：标准库已接受社区贡献
- 2026-08-12：Mojo 1.0 发布（源码稳定）
- 2026-08-19：**正式开源**——编译器、工具链及全部源码发布至 Modular GitHub 仓库
- 暂未接受编译器相关贡献，计划年底前开放

## 在本库的定位

Mojo 是本库首个"AI 原生编程语言实体"——其设计哲学（Python 兼容 + 系统编程 + AI 优化）与 [[Coding-Agent]] 生态高度相关。Mojo 开源标志"AI 友好型语言栈"进一步丰富，与 [[Python]] / [[Rust]] 形成对照。
