# GitLab

## 是什么

提供完整 DevOps 平台的软件公司，核心产品 GitLab.com（SaaS）和 GitLab CE/EE（自托管）。支持 Git 版本控制、CI/CD、Issue 跟踪、代码审查、安全扫描等全生命周期开发流程。

## 核心功能

- **Git 仓库管理**：基于 Git 的版本控制
- **GitLab CI/CD**：原生集成 CI/CD 管道
- **Merge Request**：代码审查机制（类似 GitHub PR）
- **GitLab Safety**：安全扫描、漏洞检测、依赖审查
- **GitLab AI**：AI 辅助代码审查、文档生成、问题分类

## 与 GitHub 的对比

| 特性 | GitHub | GitLab |
|------|--------|--------|
| 市场份额 | 更大（开发者首选） | 次之 |
| CI/CD | GitHub Actions | GitLab CI（原生更强） |
| 自托管 | 支持（GitHub Enterprise） | 原生友好 |
| 开源协议 | MIT | MIT |
