# vol-rs

## 是什么

vol-rs 是 [Volatility 3](https://github.com/volatility-framework/volatility3) 内存取证框架的 Rust 重写，由 daffainfo 维护。提供与原版相同输出，但性能显著提升。

## 核心功能

- **内存取证**：分析进程、线程、句柄、网络连接、注册表等
- **Rust 高性能**：相比 Python 原版速度更快，内存占用更低
- **跨平台**：支持 Linux / macOS / Windows 镜像分析
