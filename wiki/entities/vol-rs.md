# vol-rs

## 是什么

vol-rs 是用 Rust 编写的命令行磁盘卷管理工具，用于查看和管理文件系统卷信息。

## 核心功能

- **卷信息查看**：显示磁盘分区、挂载点、文件系统类型
- **卷操作**：创建、删除、格式化卷
- **跨平台**：支持 Linux / macOS / Windows

## 在 GitHub 生态中的角色

- 是 GitHub 相关工具链的辅助工具之一
- 与 Git 版本控制、开源协作生态配合使用
