# MAI-Thinking-1

## 是什么

微软（Microsoft AI）**首个自研推理模型**，由 Microsoft AI CEO Mustafa Suleyman 于 2026-08-13 宣布。从零开始构建（非基于第三方模型微调），现已在 Microsoft Foundry 上线。这是微软摆脱对 OpenAI 模型单一依赖、建立自有前沿模型能力的关键信号。

## 核心特性

- **从零构建**：非基于第三方模型微调，体现微软自有模型训练能力
- **推理模型定位**：与 OpenAI o 系列 / Anthropic Claude 思考模式 / DeepSeek-R1 同属推理模型谱系
- **Microsoft Foundry 独占上线**：通过微软自有 AI 平台分发，非通用 API
- **战略意义**：微软此前 AI 能力深度绑定 OpenAI（[OpenAI 贡献七成 AI 收入](https://aihot.virxact.com/daily/2026-08-07)），MAI-Thinking-1 标志其自研模型线正式落地

## 适用场景

- 微软生态内的推理增强任务（Foundry / Copilot）
- 需要推理模型的复杂决策 / 数学 / 编码场景
- 不便依赖 OpenAI 模型的合规 / 私有化场景（待微软明确）
