# Kiro

## 是什么

Kiro 是一款软件开发智能体（AI Coding Agent），由 OpenAI 与 AWS 合作优化，将 GPT-5.6 模型家族集成到其中，为开发者提供更高效的代码生成与任务完成能力。

## 核心特性

- **GPT-5.6 模型家族集成**：内置 Sol、Terra 和 Luna 三款模型，适配不同场景
- **成本优化**：在 Terminal-Bench 2.1 测试中，GPT-5.6 Terra 在 Kiro 内完成任务成本降低约 82%
- **更少迭代、更高价值**：通过优化 token 使用效率，帮助开发者产出更高质量的代码

## 适用场景

- 软件开发智能体工作流
- 需要高效率代码生成的编程任务
- 对成本敏感的批量代码生成场景
