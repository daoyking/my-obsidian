# Git

## 是什么

分布式版本控制系统，由 Linus Torvalds 创建。现代软件开发的基石工具，支持分支管理、协作工作流、代码审查。

## 核心概念

- **仓库（Repository）**：项目版本历史
- **分支（Branch）**：并行开发线
- **提交（Commit）**：版本快照
- **远程（Remote）**：协作同步点
