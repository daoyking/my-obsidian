# TypeScript

## 是什么

微软开源的 JavaScript 超集，为 JS 增加静态类型系统。编译（转译）为 JS 运行。大型项目类型安全的基石。

## 核心特性

- 静态类型注解：`type` / `interface` / 泛型
- 类型推导与窄化（narrowing）
- 工具链：`tsc` 编译器、`tsconfig.json`
- 与现代框架深度集成（React / Vue / Solid 均一等公民支持）

## 适用场景

- 中大型项目、团队协作
- 库 / SDK 开发（提供类型定义）
- 任何想降低运行时类型错误的项目

## 在我项目中的使用

- `my-vue3-vite-ts` · `my-solidjs-app-ts` — TS + 框架实践
- `core` / `CCT` / `ecommercestore-supplier-web` — 业务项目类型安全
