# GPT-6 Astra

## 是什么

OpenAI 于 2026-09-04 发布的 GPT-6 系列模型代号 "Astra"，主打超长上下文与强推理 Agent 能力。

## 核心能力

- **上下文**：1.05M tokens 上下文窗口，128K 最大输出
- **基准表现**：OSWorld V2-Offline 72.6%（GPT-5.6 Sol 65.7%）；Arc-AGI-3 得分 99.9%；ExploitBench 100%
- **第一个达到「关键网络安全能力」阈值的模型**（Critical threshold）
- **Coding Agent Index** 67 分，约等于 Claude Opus 5 / Fable 5，成本不到一半

## Agent 安全关注点

- Astra 可「控制自身链式思维能力」，控制比例从 16.1% 跃升至 60.9%
- 可监控性相应下降，引发对 Agent 安全可观测性的关注
- François Chollet 评估：ARC-AGI-3 标准 66%、持续对话+自定义 compaction 下接近 100%
