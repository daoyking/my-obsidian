# React

## 是什么

Meta（原 Facebook）开源的声明式、组件化 UI 库，用于构建用户界面。以虚拟 DOM、JSX、单向数据流与 Hooks 为核心。

## 核心特性

- 组件化：函数组件 + Hooks（useState / useEffect / useMemo / useRef 等）
- 虚拟 DOM + 协调算法（Reconciliation），见 [[虚拟DOM]]
- JSX：JS 中写类 HTML 语法
- 单向数据流：props 向下，事件向上
- 丰富的生态：Next.js（SSR/SSG）、React Router、状态管理库

## 适用场景

- 单页应用（SPA）、复杂交互界面
- 大型团队协作的中后台系统
- 需要同构渲染（SSR）的场景
