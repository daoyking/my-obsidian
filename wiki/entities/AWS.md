# AWS

## 是什么

亚马逊云科技（Amazon Web Services），全球最大公有云服务商，提供计算、存储、数据库、AI/ML 等全栈云服务。

## 核心 AI 产品

- **Bedrock**：托管式大模型 API（Anthropic Claude、Meta Llama、AI21 等）
- **Trainium / Inferentia**：自研 AI 训练/推理芯片
- **SageMaker**：ML 全生命周期平台

## 在 AI 生态中的角色

- 是多数 AI 初创公司的首选云基础设施
- Kiro（OpenAI × AWS 合作智能体）基于 AWS 部署
- 提供低成本 GPU 实例（如 G5/G6），降低 AI 开发门槛
