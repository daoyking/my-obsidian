# Kitesurf

## 是什么

Cloudflare 推出的专为 AI 智能体设计的浏览器，完全运行在 Workers 上，基于 V8 隔离环境。现已在 Browser Run 中免费开放测试。

## 核心特性

- 代理优先（Agent-first）设计：为 AI 智能体而非人类用户优化
- 完全运行在 Cloudflare Workers 上（V8 隔离环境），无传统浏览器沙箱开销
- 通过 Browser Run 免费测试
- 适合 Agent 网页交互、表单填写、数据抓取等自动化场景

## 适用场景

- AI Agent 的网页交互和自动化
- 无头浏览器替代方案（更高性能、更低开销）
- 需要隔离环境的安全浏览任务
