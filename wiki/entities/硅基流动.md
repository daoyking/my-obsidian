# 硅基流动（SiliconFlow）

## 是什么

中国 AI 基础设施公司，提供开源模型推理平台与 API 服务，以 Day-0 支持、低定价与兼容主流工具（Claude Code、Codex、Cursor）著称。

## 核心动态

- **Hy4 preview 上线（2026-09-15）：** 开源模型 Hy4 preview，770B 总参数、每 token 激活 49B、支持 1M 上下文，采用 Apache 2.0 协议，面向编码、分析、研究与复杂实际工作。用户可将其接入 Claude Code、Codex、Cursor 等已有工具。定价为每 1M tokens 输入 $0.834、输出 $2.501、缓存 $0.042。来源：[[raw/articles/ai-hot-2026-09-15]]
- **DeepSeek V4 Pro Day-0 上线（2026-08-15）：** 硅基流动提供 DeepSeek V4 Pro 的 Day-0 支持，是国产前沿模型商业化落地的早期案例。来源：[[raw/articles/ai-hot-2026-08-15]]
