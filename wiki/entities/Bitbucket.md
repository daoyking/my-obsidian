# Bitbucket

## 是什么

Atlassian 公司旗下的代码托管平台，主要为开发团队提供 Git 和 Mercurial 版本控制服务。相比 GitHub，Bitbucket 在与企业工具链（如 Jira、Trello）集成方面更具优势。

## 核心功能

- **代码托管**：支持 Git 和 Mercurial 仓库
- **CI/CD 集成**：与 Bitbucket Pipelines 原生集成
- **Pull Request**：代码审查机制
- **Jira 集成**：与 Atlassian 项目管理工具无缝连接

## 与 GitHub/GitLab 的对比

- 优势：企业级集成、私有仓库免费
- 劣势：开源社区活跃度较低
