# skillhub-daily

## 是什么

本机已安装的 Skill（`~/.workbuddy/skills/skillhub-daily`），用于从 SkillHub（skillhub.cn）抓取每日 Skill 推荐：扫描全站 Top100 + 7 大分类各 Top20（共 240 个 Skill），产出推荐清单。本页为 Lint 补建的实体页。

## 核心特性

- 覆盖范围：SkillHub 全站 Top100 + 7 大分类各 Top20 = 240 个 Skill
- 产出：每日推荐清单，用于发现可安装的新 Skill（如 [[Mac-免费效率工具推荐-2026-09]] 这类日报任务）

## 在本库中的使用

- 与 [[WorkBuddy]] 的自动化体系配合：每日推荐 → 人工/AI 判断值得装的 → 安装并同步到 Claude Code / Gemini CLI（见用户记忆中的 skill 符号链接同步约定）
- Mac/iPhone 免费 App 推荐日报流程中曾引用其配置（IMA 知识库 + qclaw 微信推送）
