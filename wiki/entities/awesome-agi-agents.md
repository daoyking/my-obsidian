# awesome-agi-agents

## 是什么

AGI Agents 精选资源合集（中文为主），由「云中江树」维护，持续更新。2026-08-11 快照时 554 stars、41 forks，协议 CC BY-NC 4.0（署名-非商业性使用）。是 Agent 生态的横向全景图——从论文、框架、平台到前沿项目一站集齐。

## 核心特性

- **论文区**：LLM-Agent-Survey 综述、Toolformer（LLM 自我学会用工具）、HuggingGPT（模型编排）、ToolLLM（16000+ 真实 API 工具评测）、AgentBench（8 环境 Agent 基准）
- **2024-2026 重要项目**（持续活跃）：[[MCP]]、[[Mastra]] 同源生态 LangGraph、CrewAI、OpenAI Agents SDK、smolagents、Pydantic AI、A2A（Agent 互连协议）、Claude Code、Gemini CLI、OpenHands、SWE-agent、Browser Use、Google ADK、Microsoft Agent Framework、AG-UI
- **前沿项目**：AutoGPT、gpt-engineer、MetaGPT、generative_agents（斯坦福 AI 小镇）、opencode、Aider、goose、DeerFlow（深度研究）、Suna
- **Agents 开发平台**：langchain、autogen、Dify、Letta（有状态 Agent）、Agno、bisheng 毕昇、SuperAGI
- **Curated List 导航**：awesome-ai-agents、[[awesome-llm-apps]]（本页提到的那个仓库已于 2026-09-01 单独 Ingest，见其条目）、punkpeye/awesome-mcp-servers（MCP Server 精选导航，见 [[Agent开发学习计划-Python路线]] 资源清单）

## 适用场景

- Agent 生态横向调研：想知道「2024-2026 有哪些主流框架/平台/协议」时的一站式清单
- 学习路线选型参考：[[Agent开发学习计划-Python路线]] Week 4（框架周）对比 LangGraph/CrewAI/OpenAI Agents SDK 时对照本项目条目
- 论文阅读索引：想从论文层面理解 Agent（工具使用、评测、编排）时从论文区切入
