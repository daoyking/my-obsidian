# VSCode

## 是什么

微软开源的代码编辑器，前端开发主力工具。

## 核心特性

- 丰富的语言服务（LSP）：[[TypeScript]] / [[Vue]] / [[React]] / [[Svelte]] / [[SolidJS]] 支持
- 集成终端、Git、调试器
- 扩展生态

## 常用插件

- Vim（配合 [[Vim]] 习惯）
- ESLint / Prettier
- 各框架官方扩展（Volar / ES7 React Snippets 等）

## 常用快捷键

- `Cmd+P` 文件跳转 · `Cmd+Shift+P` 命令面板
- `Cmd+D` 多选 · `Alt+Click` 多光标
