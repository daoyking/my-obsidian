# 小红书（AllSpark）

## 是什么

中国社交电商平台小红书（Xiaohongshu）及其 AI 研究团队 AllSpark，在搜索与 Agent 模型领域持续投入开源。

## 核心动态

- **Search Agent 模型 Iris（2026-09-15）：** 开源 Search Agent 模型 Iris，提供 35B 与 397B 两个版本，同量级成绩领先。权重与评测代码已公开，数据与训练配方将陆续公布。这标志着中国科技公司在 Search Agent 领域的开源布局加速。来源：[[raw/articles/ai-hot-2026-09-15]]
