## 能力轮廓

- **交互层**：流式渲染、工具调用可视化、human-in-the-loop 审批 UI（前端独占优势区）。
- **编排层**：用 [[Mastra]] 做多步 Agent（读简历→抓 JD→打分→建议）。
- **模型接入**：[[Vercel-AI-SDK]]（`streamText` / `generateObject` / `tool`），兼容 DeepSeek / 通义 / OpenRouter 等 OpenAI 兼容端点。
- **质量保障**：Agent [[Agent评估]]（LLM-as-judge 评测 + 数据集 + CI 回归）+ [[可观测性]]（自建 Tracer / AI SDK telemetry，可对接 Langfuse）。

## 作品集包含的四个工程（见 [[Agent开发学习计划]] W2–W5）

1. `w2-agent-chat`：Vercel AI SDK 流式聊天 + 工具。
2. `w3-rag-qa`：检索增强生成问答。
3. `w4-resume-scorer`：Mastra 多步编排 Agent（简历打分器）。
4. `w5-agent-eval`：评测（eval）+ 零依赖可观测 Tracer + Langfuse 条件式导出。
