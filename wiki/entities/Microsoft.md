# Microsoft

## 是什么

美国科技巨头，全球最大软件公司，AI 研究与商业化并重的 Tech 巨头。

## 核心 AI 布局

- **Microsoft Research**：开发 Lean 形式化证明助手（Leonardo de Moura 团队），推进形式化数学验证
- **Microsoft Foundry**：2026-09-05 上线，支持自定义模型微调与部署
- **微软 MAI-Thinking-1**：微软首个自研推理模型，从零构建
- **GitHub Copilot / Copilot Kit**：AI 编程助手生态
- **Azure / 云计算**：Azure 云与 GCP/AWS 竞争，支撑企业 AI 部署

## 与 Agent 安全/形式化验证

- Lean 形式化证明由 Microsoft Research 主导，Anthropic 用 Claude 在 Lean 上完成费马大定理形式化证明
- Microsoft 通过 Foundry 提供企业 AI 部署平台
- 参与 Open Compute Project（OCP）800VDC 直流配电标准制定
