# Qwen-MM-Plugins

## 是什么

[[Qwen]] 系列的多模态智能体插件（Multimodal Plugins），让智能体原生支持多模态——读取图片、视频和文档，编辑视频，处理 3D/CAD 等更多形态。定位是「从多模态模型 → 多模态智能体」的跃迁：把模型的多模态感知能力封装成 Agent 可直接调用的插件接口。

> seed 页：仅条目化定位与来源，待后续 Ingest 补全 API 形态、插件清单与适用边界。

## 核心特性

- 多模态输入：图片 / 视频 / 文档读取
- 多模态产出：视频编辑、3D / CAD 处理
- 与 Qwen Agent 体系原生集成（区别于外挂式多模态工具）

## 适用场景

- 多模态智能体工作流（搭配 [[Qwen]] 模型族）
- 文档/视频理解与自动化处理

## 在我项目中的使用

- （暂无直接使用）作为 [[Qwen]] 生态的多模态 Agent 能力持续关注
