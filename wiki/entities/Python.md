# Python

## 是什么

高级、解释型编程语言，以简洁语法和丰富生态著称。AI/ML 领域首选语言。

## 核心特性

- 动态类型、自动内存管理
- 丰富的标准库和第三方包（PyPI）
- 支持多种编程范式（OOP、函数式、过程式）

## AI 生态

- NumPy、Pandas、SciPy（数据处理）
- PyTorch、TensorFlow、JAX（深度学习）
- LangChain、LlamaIndex（Agent 框架）
- Transformers（Hugging Face）
