# Node.js

## 是什么

基于 V8 引擎的 JavaScript 运行时，让 JS 跑在服务端。事件驱动、非阻塞 I/O，适合 I/O 密集型场景。

## 核心特性

- CommonJS / ESM 模块
- 事件循环（Event Loop）与异步 I/O
- npm 生态（世界最大包仓库）
- 工具链：nvm 版本管理、pnpm/npm/yarn/bun 包管理

## 适用场景

- 前端工程化：构建工具、脚手架、CLI
- BFF / 轻量后端服务
- 服务端渲染（SSR）

## 在我项目中的使用

- `king-cli` — 自研 CLI 工具
- `midway-project` — Midway.js 后端框架实践
- 各前端项目的构建与脚本依赖
