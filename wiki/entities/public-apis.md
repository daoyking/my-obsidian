# public-apis

## 是什么

免费公共 API 的集体清单（A collective list of free APIs），GitHub 上 star 数最高的仓库之一（2026-08-11 快照 455k stars、50k forks，MIT 协议）。社区成员长期手动策展，按领域分类整理 1400+ 个免认证/免费可用的公开 API，被誉为「API 宝库」。

## 核心特性

- **领域分类**：Animals / Books / Business / Calendar / Cloud Computing / Cryptocurrency / Currency Exchange / Database / Development / Education / Environment / Events / Finance / Food & Drink / Games / Geocoding / Government / Health / Jobs / Machine Learning / Music / News / Open Data / Patent / Personality / Photography / Science / Security / Shopping / Social / Sports / Test Data / Text Analysis / Weather 等 40+ 类
- **每条 API 标注**：名称 + 描述 + 是否需要 Auth + HTTPS 支持 + CORS 支持 + 官方链接，一眼可筛选
- **社区维护**：通过 issue/PR 贡献，长期活跃更新
- 注意：README 头部含 APILayer 赞助商推广内容（商业 API 套件），与免费清单本体无关

## 适用场景

- Agent/应用开发时找现成数据源：天气、新闻、加密货币行情、金融汇率、地理编码、文本分析等
- [[Agent开发学习计划-Python路线]] Week 2（Tool Calling 实验）与 Week 10-11（验收项目）的 API 弹药库——`get_weather`、新闻聚合、日历类工具都可从这里挑
- 前端/全栈开发的 mock 数据与真实数据替代方案
