# ChromeAppHeroes（谷粒-Chrome插件英雄榜）

## 是什么

为优秀 Chrome 插件写中文说明书的开源项目（zhaoolee 维护），"谷粒-Chrome插件英雄榜"。2026-08-12 快照 25.8k stars、2.6k forks，Docsify + GitHub Pages 构建（`zhaoolee.com/ChromeAppHeroes`），仓库内 backup/ 目录附插件离线包，公众号「0加1」同步更新。

## 核心特性

- **133 篇中文插件说明书**（编号 001-133 持续更新），每篇含：插件下载/安装、功能演示、使用教程、适用场景，最新已覆盖 2026 年的 MV3 时代插件
- **内容分类丰富**（代表性条目）：
  - 开发工具：XPath Helper、JsonFormatter、Restlet Client（API 调试）、Console Importer（控制台直接用 npm 军火库）、GitZip、Enhanced GitHub、Sourcegraph、octotree
  - 效率：Vimium（Vim 键位操作网页）、OneTab（标签页收纳）、Scroll To Top、Smart TOC（自动目录）、Go to Tab、Quickey Launcher
  - 阅读翻译：Immersive Translate（沉浸式翻译）、Saladict（划词翻译）、SimplRead（简悦）、Wikiwand、Language Learning with Netflix & YouTube
  - 下载媒体：B 站下载助手、YouTube Subtitle Downloader、Video Screenshot、PowerfulPixivDownloader、Get cookies.txt LOCALLY（配合脚本自动化下载）
  - 隐私去广告：uBlock Origin / uBlock Origin Lite（MV3 版）、I don't care about cookies、AdBlock
  - 专注健康：Marinara 番茄钟、潮汐 Tide（白噪音）、假装水墨屏、Dark Reader
  - 趣味实用：CopyFish OCR、EXIF Viewer、Get Favicon、RSSHub Radar、Feedbro、Linkclump
- **backup/ 离线包**：多数条目附插件源码 zip 备份（如 `backup/118-immersive-translate`），可离线安装
- 特别篇：手机端使用 Chrome 插件（102）、星愿浏览器（104）、Edge 安装 Chrome 扩展（042）

## 适用场景

- Chrome 插件选型：找效率/开发/阅读工具时按编号目录速查
- 开发者工具链：与 [[Node.js]]、[[Vim]] 生态衔接（Console Importer 用 npm、Vimium 复刻 Vim 操作）
- 插件原理参考：backup/ 离线包可直接解包阅读插件实现（与本库 [[Chrome]] 相关）
