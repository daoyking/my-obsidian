# Vim

## 是什么

模式化文本编辑器，以高效的键盘操作著称。在 Obsidian 中通过 Vim 模式插件启用（见 `~/about-project/obsidian/.obsidian.vimrc`）。

## 核心特性

- 模式：Normal / Insert / Visual / Command
- 动词 + 名词组合操作（如 `dw` 删词、`ci"` 改引号内）
- 宏、寄存器、标记（mark）

## 适用场景

- 不离键盘的高速编辑
- 在 Obsidian / VSCode 中启用 Vim 模式统一编辑习惯

## 常用快捷键

- `hjkl` 移动 · `w/b` 词移动 · `dd` 删行 · `yy` 复制行
- `:%s/old/new/g` 全局替换 · `.` 重复
