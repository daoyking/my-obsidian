# 微调（Fine-tuning）

## 定义

在已预训练的大模型基础上，用特定任务/领域的数据继续训练，使其在该任务上表现更好。是让通用模型「专业化」的主要手段。

## 为什么重要

- 预训练模型通用但不够专；微调用少量数据即可获得大幅提升
- 是企业落地 LLM 的核心路径（领域适配、风格统一、能力注入）
- 衍生出参数高效微调（PEFT），如 LoRA，大幅降低成本

## 核心机制与分类

- **全量微调（Full FT）**：更新所有参数，效果好但成本高、易灾难性遗忘
- **SFT（监督微调）**：用「指令-回答」对训练，对齐人类意图
- **PEFT**：只训练少量参数
  - **LoRA**：低秩矩阵分解，冻结原权重，训练注入的小矩阵
  - **QLoRA**：LoRA + 4bit 量化，单卡可微调大模型
- **指令微调（Instruction Tuning）**：SFT 的常见形式

## 示例

```
# LoRA 思路（伪代码）
base_model.freeze()
lora_A = init_low_rank(d, r); lora_B = init_low_rank(r, d)  # r << d
output = base_model(x) + (x @ lora_A) @ lora_B
# 只训练 lora_A, lora_B
```
