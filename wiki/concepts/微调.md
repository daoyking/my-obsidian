# 微调（Fine-tuning）

## 定义

在已预训练的大模型基础上，用特定任务/领域的数据继续训练，使其在该任务上表现更好。是让通用模型「专业化」的主要手段。

## 为什么重要

- 预训练模型通用但不够专；微调用少量数据即可获得大幅提升
- 是企业落地 LLM 的核心路径（领域适配、风格统一、能力注入）
- 衍生出参数高效微调（PEFT），如 LoRA，大幅降低成本

## 核心机制与分类

- **全量微调（Full FT）**：更新所有参数，效果好但成本高、易灾难性遗忘
- **SFT（监督微调）**：用「指令-回答」对训练，对齐人类意图
- **PEFT**：只训练少量参数
  - **LoRA**：低秩矩阵分解，冻结原权重，训练注入的小矩阵
  - **QLoRA**：LoRA + 4bit 量化，单卡可微调大模型
- **指令微调（Instruction Tuning）**：SFT 的常见形式

## 示例

```
# LoRA 思路（伪代码）
base_model.freeze()
lora_A = init_low_rank(d, r); lora_B = init_low_rank(r, d)  # r << d
output = base_model(x) + (x @ lora_A) @ lora_B
# 只训练 lora_A, lora_B
```

## LoRA 实战教程：DistilBERT + IMDb 情感分析（2026-08-10）

来自 [[raw/articles/ai-hot-2026-08-10]]（MarkTechPost 教程）：

基于 Stanford IMDb 数据集的端到端情感分析流程，对比两条技术路线：
- **基线**：TF-IDF + 逻辑回归
- **LoRA 微调**：DistilBERT（DistilBERT 本身是 [[蒸馏]] 产物）

评估维度较完整，值得作为 LoRA 实战参考：
- 指标：准确率 / macro-F1 / ROC-AUC / **期望校准误差（ECE）**
- 可解释性：词级遮挡显著性分析
- 鲁棒性：置信错误、长度影响分析
- 半监督：用未标注 IMDb 数据做置信度伪标注，比较半监督模型与基线
- 工程：保存合并后的 Transformer 用于推理

**启示**：该教程示范了"基线对照 + 多维评估 + 半监督扩展"的完整微调实验设计，可作为本库 [[机器学习项目工作流]] 的具体案例参考。
