# 响应式

## 定义

数据变化时，依赖该数据的副作用（视图更新、计算值、监听器）自动重新执行的机制。是现代前端框架「数据驱动视图」的根基。

## 为什么重要

- 让开发者只管改数据，框架自动同步视图
- 决定了框架的更新粒度与性能上限

## 核心机制

- **依赖收集**：读取响应式数据时记录「谁用了它」
- **派发更新**：数据变更时通知所有依赖重新执行
- 实现方式：
  - Vue2：`Object.defineProperty` 劫持 getter/setter
  - Vue3 / Solid：`Proxy` 代理对象
  - Solid：Signal 细粒度，更新精准到表达式
  - React：不直接响应式，靠 `setState` 触发重渲染（整体协调）

## 示例

```js
// Vue3 风格
const count = ref(0)
count.value++ // 视图自动更新
```
