# 投机解码

## 定义

> 投机解码（Speculative Decoding）是一种推理加速技术，通过"草稿模型"快速生成候选 token，再由"主模型"验证，在不改变输出质量的前提下显著提升生成速度。

## 为什么重要

- 大模型推理成本占 AI 应用总成本的绝大部分
- 投机解码可在不重新训练主模型的情况下实现 2-3 倍加速
- 草稿模型仅需约 300M 参数，远低于主模型

## 核心机制

1. **草稿模型生成**：小参数模型快速生成多个候选 token
2. **主模型验证**：大模型并行验证草稿 token 的正确性
3. **接受/拒绝**：接受验证通过的 token，拒绝则回退并重生成

## 示例

```python
# 概念示意（非真实代码）
draft_model.generate(candidates=5)  # 草稿模型生成 5 个候选
main_model.verify(candidates)       # 主模型并行验证
accepted_tokens = [t for t in candidates if main_model.accept(t)]
```
