# 模型评估

## 定义

模型评估（Model Evaluation）是量化评估 LLM 在特定任务上表现的系统性方法，包括基准测试、人工评测、自动化评估等。

## 评估维度

| 维度 | 说明 |
|------|------|
| **准确性** | 答案与标准答案的匹配度 |
| **安全性** | 是否产生有害/偏见输出 |
| **有用性** | 对人类任务的帮助程度 |
| **效率** | 推理速度、token 消耗 |
| **一致性** | 多次运行的稳定性 |

## 常用基准

- **MMLU**：多任务语言理解（57 个学科）
- **HumanEval**：代码生成
- **GSM8K**：数学推理
- **LiveBench**：对抗性基准测试
- **LangCodeBench**：编码智能体专项

## 评估方法

- **零样本**：直接提问
- **少样本**：提供示例
- **链式思考**：引导逐步推理
- **双盲评估**：消除评估者偏见
