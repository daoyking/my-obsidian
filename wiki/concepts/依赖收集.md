# 依赖收集

## 定义

响应式系统的核心机制：在副作用（effect）读取响应式数据时**记录「谁依赖了这个属性」**（track），在数据变更时**通知所有依赖重新执行**（trigger）。这是 [[响应式]]「数据驱动视图」能自动更新的根基。

## 为什么重要

- 没有依赖收集，框架不知道数据变了该更新哪部分视图
- 决定更新粒度：属性级（细）vs 组件级（粗）
- Vue3 / Solid 靠它实现精准更新；React 不做依赖收集，靠 setState 整体重渲染

## 核心机制

三要素：
1. **targetMap**：`WeakMap<target, Map<key, Set<effect>>>`，记录「哪个对象的哪个属性被哪些 effect 依赖」
2. **track(target, key)**：在 effect 执行期间读取属性时，把当前活跃 effect 加入对应 Set
3. **trigger(target, key)**：属性变更时，从 targetMap 取出 effect 集合并执行

```
targetMap (WeakMap)
 └─ target (Map)
     └─ key (Set<ReactiveEffect>)
         └─ effect1, effect2 ...
```

## mini-vue 中的实现（Vue3 / Proxy）

来自 [[raw/articles/mini-vue-overview]]：
- `reactivity/src/dep.ts` 与 `effect.ts` 实现 track/trigger
- `effect(fn)` 注册副作用，执行 fn 时建立依赖关系
- `effect.scheduler`：允许自定义触发时的执行方式（如异步批量更新）
- `effect.stop`：手动停止依赖追踪
- 配合 Proxy 的 get（触发 track）/ set（触发 trigger），见 [[响应式]]

## Vue2 的三件套：Observer / Dep / Watcher（来自 [[raw/articles/vue-technology-revealed]]）

Vue2 用 `Object.defineProperty` 实现依赖收集，三角色：
- **Observer**：遍历对象每个 key，定义 getter/setter
- **Dep**：每个 key 一个依赖管理器；getter 时 `dep.depend()` 收集当前 Watcher
- **Watcher**：执行 getter 前把自己设为 `Dep.target`，触发依赖收集；setter 时 `dep.notify()` 通知所有 Watcher 更新

```
读取 obj.key → getter → Dep.depend() → Watcher 入 Dep
修改 obj.key → setter → Dep.notify() → 所有 Watcher update
```

Vue3 把这三件套抽象为 `targetMap + track + trigger`（见上），但本质同为「读时收集、写时通知」。

## 示例

```ts
const state = reactive({ count: 0 })
effect(() => { console.log(state.count) }) // 读取→track
state.count++ // 写入→trigger→effect 重新执行→打印 1
```
