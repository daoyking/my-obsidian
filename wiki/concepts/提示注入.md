# 提示注入（Prompt Injection）

## 定义

攻击者通过**数据通道**（工具返回的内容、检索到的文档、网页正文等）注入恶意指令，操纵 LLM 偏离原本系统提示的意图。是上下文安全的核心威胁（《AI Agents in Depth》2.4.7）。

## 与越狱攻击的区别

- [[越狱攻击]]：**用户侧**主动构造提示词绕过护栏（用户即攻击者）
- 提示注入：**数据侧**——用户无害，但 Agent 读取的外部内容里藏了指令（攻击者控制被读取的数据）
- Agent 时代提示注入更危险：Agent 会执行动作，注入可导致实际损害（见 [[Agent安全]]）

## 两种形态

- **直接注入**：用户直接在输入里夹带指令
- **间接注入**：指令藏在 Agent 读取的网页/文档/邮件里（Agent 时代主要威胁）

## 防御方向

- 数据与指令分离：明确哪些是「不可信数据」
- 输入清洗、分隔符隔离（```、<untrusted>）
- 输出约束、工具权限最小化
- 人机协同：关键操作需人确认

## Anthropic 的突破性进展（2026-08-10）

来自 [[raw/articles/ai-hot-2026-08-10]]：

Anthropic 的 Boris Cherny 表示，通过**模型训练**已基本解决 Claude 模型在实际使用中的提示注入威胁。独立研究者的基准测试显示，叠加**模型训练 + 输入探测 + 意图分类器**多层防御后，未见过的间接提示注入攻击成功率可降至约 0。

作为配套，Claude Code 的 auto 模式将于下周默认开启（见 [[Claude-Code]]）——安全护城河筑牢后才放开自主执行权限。

**定位与启示**：
- 这是迄今对"间接提示注入"（Agent 时代主要威胁）最乐观的工程级进展。若可复现，[[Agent安全]] 的核心矛盾将部分消解
- 但"基本解决"≠根除：多层防御暗示单一手段仍不足，攻击者可能转向分类器/探测器本身的对抗
- "模型训练"路径意味着防御能力绑定具体模型，跨模型迁移性待验证

### Omnigent 上下文策略的组合攻击防御（2026-08-11）

来自 [[raw/articles/ai-hot-2026-08-11]]：

Omnigent 的 Contextual Policies 在组合上下文中识别并拦截"致命三重奏"组合攻击——多个无害请求叠加形成恶意行为，单请求层面不设防。这与本页"多层防御"思路互补：判定从"单个请求 / 数据"上移到"组合上下文"，更契合 Agent 多轮、多工具调用的真实形态。

**定位**：间接提示注入的防御从"清洗单条数据"走向"理解请求序列的意图组合"，是 [[上下文工程]] 在安全侧的延伸；与 [[Agent安全]] 的"致命三重奏"事件互为表里。
