# 工具调用

## 定义

工具调用（Tool Use / Function Calling）是 LLM 通过结构化输出（JSON）请求调用外部函数的能力，使模型能够执行计算、访问数据、操作文件等超出文本生成的任务。

## 工作原理

1. **函数定义**：开发者提供函数签名（名称、参数、描述）
2. **模型选择**：LLM 判断是否需要调用工具、调用哪个、参数是什么
3. **执行函数**：运行时调用函数，返回结果
4. **模型续生成**：LLM 根据结果继续生成响应

## 与 Agent 的关系

- **工具调用 = Agent 的基础能力**
- 多个工具调用 + 循环 = 完整 Agent 工作流
- Vercel AI SDK 的 `tool()` 抽象简化工具定义
