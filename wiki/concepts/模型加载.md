# 模型加载

## 定义

模型加载（Model Loading）是将训练好的模型权重从存储介质加载到计算设备（CPU/GPU/TPU）并准备推理的过程。

## 加载流程

1. **权重文件读取**：从磁盘/网络加载 .safetensors / .bin / .pt 文件
2. **模型架构实例化**：根据配置文件创建模型结构
3. **权重映射**：将权重填入模型层
4. **设备转移**：将模型移至目标设备（GPU/TPU）
5. **推理准备**：设置推理模式（eval mode）

## 优化技术

| 技术 | 说明 |
|------|------|
| **量化** | FP16/BF16/INT8 降低精度提升速度 |
| **模型并行** | 跨多 GPU 拆分模型 |
| **管道并行** | 分层流水线并行 |
| **GGUF** | 本地量化格式（llama.cpp） |

## 相关工具

- **Transformers**（Hugging Face）：通用模型加载
- **llama.cpp**：本地量化模型加载
- **vLLM**：高吞吐推理服务
