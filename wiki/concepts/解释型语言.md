# 解释型语言

## 定义

解释型语言（Interpreted Language）是指源代码在运行时由解释器逐行翻译执行，而非预先编译为机器码的语言。

## 与编译型语言对比

| 特性 | 解释型 | 编译型 |
|------|--------|--------|
| 执行方式 | 运行时逐行解释 | 预先编译为机器码 |
| 执行速度 | 较慢 | 较快 |
| 开发效率 | 高（快速迭代） | 低（需编译） |
| 典型语言 | Python, JavaScript, Ruby | C, C++, Rust, Go |
| 跨平台性 | 好（只需解释器） | 需重新编译 |

## Python 的解释执行

- **CPython**：最流行的 Python 实现，使用字节码 + 解释器
- **PyPy**：JIT 编译优化，速度接近 C
- **执行流程**：源码 → 字节码 → 解释执行

## AI 开发中的角色

- **Python 主导 AI**：动态 + 解释型特性使原型开发快速
- **JavaScript/TypeScript**：Web AI、浏览器端推理
- **混合栈**：Python 后端 + TS 前端是 AI 应用常见架构
