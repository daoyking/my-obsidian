# 云原生

## 定义

云原生（Cloud Native）是一套构建和运行应用程序的技术栈，充分利用云计算模型的优点——弹性、可扩展、持续交付。

## 核心技术

| 技术 | 说明 |
|------|------|
| **容器化** | Docker / containerd，应用打包与隔离 |
| **编排** | Kubernetes，容器调度与管理 |
| **微服务** | 拆分为独立部署的服务 |
| **服务网格** | Istio / Linkerd，服务间通信 |
| **CI/CD** | 自动化构建、测试、部署 |
| **不可变基础设施** | 声明式配置，基础设施即代码 |

## 云原生与 AI

- **模型部署**：Kubernetes + KServe / Seldon Core
- **向量数据库**：Milvus / Weaviate 云原生部署
- **GPU 调度**：Kubernetes GPU Operator
