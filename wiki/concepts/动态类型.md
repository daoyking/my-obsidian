# 动态类型

## 定义

动态类型（Dynamic Typing）是指变量类型在运行时确定，而非编译时声明的编程语言特性。

## 与静态类型对比

| 特性 | 动态类型 | 静态类型 |
|------|---------|---------|
| 类型检查 | 运行时 | 编译时 |
| 灵活性 | 高 | 低 |
| 错误发现 | 晚（运行时） | 早（编译时） |
| 开发速度 | 快 | 慢 |
| 典型语言 | Python, JavaScript, Ruby | TypeScript, Java, Rust |

## Python 的动态类型

Python 是典型的动态类型语言：
- 变量无需声明类型：`x = 1`，`x = "hello"` 均可
- 类型检查在运行时进行
- 配合类型注解（Type Hints）可提供静态分析支持

## 在 AI 开发中的角色

- **Python 主导 AI**：动态类型使原型开发快速
- **TypeScript 补充前端**：静态类型提供工程化保障
- **混合实践**：Python + mypy / TypeScript 是常见组合
