# 多模态大模型（MLLM）

## 定义

能同时理解和生成多种模态（文本、图像、音频、视频）的大语言模型。在 LLM 基础上接入模态编码器（如视觉编码器）与对齐层，实现跨模态推理。

## 为什么重要

- 真实世界本就是多模态的，纯文本模型天花板有限
- 多模态理解是通往 AGI 的可能路径之一
- 前端工程师的强相关方向：图像理解 → 交互、UI 截图理解 → 自动化

## 核心机制

1. **模态编码器**：如 CLIP/SigLIP 视觉编码器，把图像变成向量
2. **对齐/投影层**：把视觉向量映射到 LLM 的词向量空间（MLP / Q-Former / Cross-Attention）
3. **LLM 主干**：融合多模态输入做推理生成
4. 典型：GPT-4V、Gemini、Qwen-VL、LLaVA（开源代表）

```
图像 → 视觉编码器 → 投影层 ─┐
                              ├→ LLM → 文本/多模态输出
文本 token embedding ────────┘
```
