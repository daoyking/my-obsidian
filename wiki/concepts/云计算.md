# 云计算

## 定义

云计算（Cloud Computing）是将计算资源（服务器、存储、网络、数据库、软件）通过互联网按需提供的模式，用户无需管理物理基础设施。

## 主要服务模式

| 模式 | 说明 | 代表服务 |
|------|------|---------|
| IaaS | 基础设施即服务，提供虚拟机、存储、网络 | AWS EC2、Azure VM、Google Compute Engine |
| PaaS | 平台即服务，提供运行时与开发工具 | AWS Elastic Beanstalk、Google App Engine |
| SaaS | 软件即服务，直接提供应用 | Gmail、Microsoft 365、Notion |

## 与 AI Agent 的关系

- 常驻 Agent（Always-on Agent）通常部署在云平台上（如 Cloud Run、Azure Functions）
- 成本敏感：Cloud Run 实例约 $5.70/月（1 vCPU/1Gi/共享 CPU）可 24/7 运行
- 多云策略降低供应商锁定风险

## 主要厂商

- **AWS**（Amazon）：市场份额最大，服务最广
- **Microsoft Azure**：企业市场强，与 Office/GitHub 生态整合
- **Google Cloud**：AI/ML 工具链领先
- **阿里云/腾讯云**：中国市场主流
