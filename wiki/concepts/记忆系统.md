# 记忆系统（Agent Memory）

## 定义

让 Agent 跨会话保留与调用信息的能力体系。把上下文管理从「当前对话」延伸到「持久化知识」，让 Agent 不仅记住当下，还能积累经验。

## 为什么重要

- 单靠上下文窗口有限且会丢失——记忆系统让 Agent 长期可用
- 是 [[上下文工程]] 的跨会话延伸
- 本知识库本身就是一个外部记忆系统（raw + wiki）

## 三层次评估框架

来自 [[raw/papers/ai-agents-in-depth]] 第 3 章：
1. **短时/工作记忆**：当前上下文窗口内
2. **长时记忆**：跨会话持久化（向量库、知识库）
3. **跨会话策略记忆**：Agent 自身行为模式的沉淀

## 认知类型（借自认知科学）

- **情景记忆**：具体事件经历（某次对话/任务）
- **语义记忆**：事实知识（概念、定义）
- **程序记忆**：如何做事（SOP、Skill、工具用法）

## 四种存储格式

书中详述四种用户记忆存储格式（文本/结构化/可执行代码/参数化），从简单到高级演进。

## 与本知识库的映射

- 本库的 `wiki/concepts`（语义记忆）、`projects`（情景记忆）、`templates`/Skill（程序记忆）正好对应认知三类型
- 卡帕西 LLM Wiki 方法本质就是「把 Agent 的语义记忆外置成可编辑 Markdown」
