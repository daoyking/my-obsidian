# 自动更新

## 定义

自动更新（Auto Update）是软件在运行时自动检测新版本并安装更新的机制，对用户透明且无需手动操作。

## 在跨平台框架中的实现

| 框架 | 自动更新方案 | 机制 |
|------|-------------|------|
| **Electron** | `electron-updater` | 检查 GitHub Release / S3 / 自定义服务器 |
| **Capacitor** | `@capacitor-community/electron-updater` | 类似 Electron 方案 |
| **Tauri** | `@tauri-apps/plugin-updater` | Rust 实现，轻量高效 |

## 更新流程

1. **检查版本**：请求服务器获取最新版本号
2. **下载更新**：增量下载（Delta）或全量下载
3. **验证签名**：确保更新包完整性
4. **应用更新**：替换文件、重启应用
5. **回滚机制**：更新失败时自动回退
