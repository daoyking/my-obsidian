# 界面世界模型（Interface World Model）

## 定义

界面世界模型是一类新型 AI 模型，能够实时生成可交互的应用/网站界面，而非传统的视频帧序列。模型直接以图像作为交互层，支持视觉化、动态响应和开放式交互，无需中间代码表示。

## 为什么重要

- **Agent 训练新范式**：传统视觉 Agent 训练依赖固定环境，界面世界模型可生成动态变化的界面布局，使 Agent 适应真实世界不断变化的 UI
- **跳过代码中间层**：模型直接生成可交互界面，省去"生成代码→渲染界面"的中间步骤
- **降低 Agent 开发门槛**：开发者可用自然语言描述界面需求，模型自动生成可交互原型

## 核心能力

- **实时逐帧生成**：支持动态界面响应
- **开放式交互**：生成的界面元素可被点击、拖拽、输入
- **视觉化表示**：以图像而非代码为中间表示

## 首个落地产品

- **Runway Solaris（2026-08-31）**：Runway 推出的首个界面世界模型，用于训练智能体适应不断变化的界面布局。参见 [[Runway]]。
