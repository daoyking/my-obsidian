# 函数调用

> 让 LLM 在生成文本之外，输出「调用某个已声明函数 + 参数」的结构化指令，由宿主程序执行后再把结果回灌模型，是 Agent 行动能力的根基。

## 定义
模型根据 system prompt 中声明的工具 Schema（名称 / 参数 / 描述），在合适时返回 `tool_calls`；宿主用 JSON 参数本地执行函数，将结果以 `role: tool` 塞回消息历史，模型据此继续推理（见 [[ReAct]]）。

## 为什么重要
- 把「只能聊」的 LLM 变成「能做事」的 Agent：查天气、搜网页、跑代码、读写库都靠它。
- 对前端工程师是甜点区：本质是把 UI 回调换成 LLM 触发函数，心智模型高度相似。

## 核心机制
1. 声明 tools（JSON Schema + 实现函数）。
2. 请求模型，若返回 `tool_calls` → 本地执行。
3. 结果回灌消息历史 → 再次请求模型。
4. 模型输出纯文本 → 结束。
