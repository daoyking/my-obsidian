## 💡 2026-09-14 新增亮点

### Agent Island - MacBook Notch 伴侣
- 专为 Claude Code 和 Codex 会话设计
- 实时显示 Agent 状态、进度、速率限制
- 自动恢复中断的长时任务
- 安装：`brew install --cask agent-island`

### cctop - AI 编码会话监控
- 菜单栏实时显示 Claude Code/Codex/opencode/pi 状态
- 一键跳转到对应终端面板或编辑器窗口
- 轻量级，零干扰

### CodexIsland - Dynamic Island 风格
- 将 MacBook notch 变成 Dynamic Island
- 本地计算 Claude Code/Codex 速率限制和花费
- 零遥测，隐私保护

### Adrafinil - AI Agent 智能唤醒
- AI Agent 工作时保持 Mac 唤醒
- Agent 完成后自动进入睡眠
- 省电又保证任务不中断

### Scratch - 本地 AI 笔记
- 本地优先 Markdown 笔记
- WYSIWYG 编辑 + 本地 AI agent 支持
- 无云服务，数据完全本地

### OATS - 会议笔记 AI 助手
- 实时转录 + 说话人标签
- AI 自动生成摘要
- 完全离线模式可用
