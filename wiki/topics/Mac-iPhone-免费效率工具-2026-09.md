## 💡 2026-09-06 新增亮点

### Abu-Cowork（阿布）- 本地 AI 桌面助手
- 完全本地运行，数据不出本机
- 29 个内置技能：文档生成（PDF/PPTX/DOCX/XLSX）、前端设计、浏览器自动化
- 支持 12+ 云服务商（DeepSeek/Qwen/智谱/MiniMax 等）+ Ollama 本地模型
- 多 Agent 并行（最多 5 个），定时任务，Cron 触发
- 飞书/钉钉/Slack 网关接入

### AionUI - 零配置 Cowork
- 安装即用，无需 CLI 和复杂配置
- 真正能读写文件、跑脚本、做 PPT、整理资料
- 多 Agent 可视化协作

## 安装建议

- **开发者**：Hermes Agent + Abu-Cowork + osaurus + Raycast + Rectangle + iTerm2
- **普通用户**：Stats + Rectangle + Maccy + LocalSend + IINA
- **iPhone 用户**：Lazyflow + rootshell（配合 Mac 使用）
- **隐私优先**：osaurus + Abu-Cowork（本地运行，数据不上传）
