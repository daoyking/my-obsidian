# 前端工程化

## 背景

随着前端应用规模与团队扩大，如何用工程手段保障质量、效率与可维护性成为核心命题。涵盖构建、模块化、规范、测试、CI/CD、监控等。

## 关键子主题

- **构建工具**：[[Vite]] / webpack / esbuild / Rollup / turbopack
- **模块化与包管理**：ESM、pnpm/npm/yarn/bun、monorepo（turborepo）
- **语言与类型**：[[TypeScript]]
- **组件化**：见 [[组件化]]
- **代码规范**：ESLint / Prettier / Stylelint / [[Linter]]（Obsidian 内）
- **测试**：Vitest / Jest / Playwright
- **CI/CD**：GitHub Actions、自动部署
- **性能**：见 [[虚拟DOM]]、bundle 分析、懒加载

## 我的观点

- 工程化不是堆工具，是建立「让正确的事变容易、错误的事变难」的约束
- Vite 已是新项目默认选择，老项目迁移收益明显
- 类型安全 + Lint + 测试是质量三件套，缺一不可

## 待研究问题

- monorepo 在多端（Web/H5/小程序）项目中的实践
- 微前端方案选型（qiankun / Module Federation）
