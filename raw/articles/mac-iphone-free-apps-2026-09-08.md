## 一、AI Agent 类（7 款）

### 1. Goose — Block 公司开源 AI Agent（⭐54k）
- **GitHub**: https://github.com/aaif-goose/goose
- **评分**: ⭐53,956 | 500+ 贡献者 | 每周 65 次 commit
- **许可证**: Apache 2.0（完全免费）
- **最新**: v1.49.0，2026-09-03 发布
- **亮点**:
  - 原 Block（Square/Cash App）开源，2025 年捐赠给 Linux Foundation AAIF
  - 桌面应用 + CLI + API 三端支持（macOS/Linux/Windows）
  - 70+ MCP 扩展（GitHub、数据库、浏览器、Slack、Figma 等）
  - 支持 30+ LLM（Claude/GPT/Gemini/Ollama 本地模型等）
  - BYOK 模式：只用自己账号的 API，无订阅费用
  - 四种模式：自主/手动审批/智能审批/仅聊天
- **适用**: 开发者首选，代码+研究+自动化全能型 Agent
- **费用**: 完全免费，仅需模型 API 费用（Ollama 本地跑 = 0 元）

### 2. Hermes Agent — 最高星 Agent 项目（⭐241k）
- **GitHub**: https://github.com/NousResearch/hermes-agent
- **评分**: ⭐241k+
- **许可证**: MIT
- **亮点**:
  - 自我进化 Agent，一行命令安装
  - 支持 300+ LLM 模型
  - Telegram/Slack/Discord 网关接入
- **适用**: 高级用户，自动化工作流

### 3. June AI — 隐私优先本地 Agent
- **官网**: https://opensoftware.co/june
- **亮点**:
  - 开源（MIT），macOS 14+，Apple Silicon + Intel
  - TEE 可信执行环境验证，数据零保留
  - 语音转文字、会议笔记、本地 Agent 三合一
  - 免费版无信用卡，包含本地模型支持
- **费用**: Free/Pro($20)/Max($100)

### 4. Lapu AI — 权限管控桌面 Agent
- **官网**: https://lapu.ai
- **亮点**:
  - macOS/Windows，每次敏感操作需用户确认
  - 文件自动化、桌面自动化（点击/打字/截图）
  - 技能复用，可定时执行
  - 免费版含全部核心工具（每月 AI 额度有限）
- **费用**: Free / $20 / $60 / $100

### 5. OpenCoDesign — AI 设计工具
- **GitHub**: 开源，2026-05 活跃
- **亮点**:
  - 本地 AI 设计工具，文本→原型/PPT/营销素材
  - 支持多模型供应商，自带 API Key
  - 输出 HTML/React/PDF，隐私优先
- **适用**: 设计师快速原型

### 6. Agent! — macOS + iPhone 远程 Agent
- **GitHub**: https://github.com/saadqbal/Agent

### 8. Maccy — 剪贴板历史（⭐13k）

## 三、iPhone 专属（8 款）

### 1. FSNotes — 跨平台笔记（⭐10k+）
- **GitHub**: https://github.com/FSNotes/FSNotes
- **亮点**: macOS + iOS 同步，Markdown + Obsidian 兼容，iCloud 同步
- **费用**: 免费

### 2. Loop Habit Tracker — 习惯追踪
- **GitHub**: https://github.com/DevHippo/Loop
- **亮点**:
  - 完全免费，无广告，无内购
  - 精美图表，习惯强度算法
  - 支持复杂周期（每周 3 次/隔日等）

### 3. Working Copy — Git 客户端（⭐9k）
- **GitHub**: https://github.com/niltsh/working-copy
- **亮点**:
  - 最成熟的 iOS Git 客户端
  - 完整分支管理、PR、Issue
  - 适配 GitHub/GitLab

### 4. Simplenote — Markdown 笔记
- **GitHub**: https://github.com/Automattic/simplenote-ios
- **亮点**: 跨平台同步，干净 Markdown，协作支持

### 5. Standard Notes — 加密笔记
- **亮点**: 端到端加密（XChaCha-20），完全离线可用，隐私优先

### 6. NetNewsWire — RSS 阅读器
- **亮点**:
  - 开源，跨平台（Mac/iOS）
  - 无算法、无广告、无追踪
  - 支持 Feedbin/Feedly/NewsBlur

### 7. Bitwarden — 密码管理器
- **亮点**:
  - 开源，端到端加密
  - 无限量密码，跨设备同步
  - 内置密码生成器

### 8. VLC for Mobile — 万能播放器
- **GitHub**: https://github.com/videolan/vlc
- **亮点**: 支持 MKV/MP4/AVI/FLAC 等几乎所有格式，无广告
