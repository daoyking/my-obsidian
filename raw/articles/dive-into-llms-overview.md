# 《动手学大模型 Dive into LLMs》系列编程实践教程

> 本文件是 raw/ 原始层，AI 只读不改。来源：https://github.com/Lordog/dive-into-llms

## 项目定位

《动手学大模型》系列编程实践教程，由上海交通大学《自然语言处理前沿技术》（NIS8021）、《人工智能安全技术》课程（NIS3353）讲义拓展而来（教师：张倬胜），公益免费。通过简单实践帮助快速入门大模型。版本 v0.1.0，最后更新 2025-10。

## 项目动机

提供大模型相关的入门编程参考，帮助同学们快速入门大模型，更好地开展课程设计或学术研究。

## 教程目录（11 章）

| 章 | 主题 | 简介 |
|---|---|---|
| 1 | 微调与部署 | 预训练模型微调与部署：选模型→特定任务微调→部署成 Demo |
| 2 | 提示学习与思维链 | 大模型 API 调用与推理；提示词对回答的影响（如「鼓励」效应） |
| 3 | 知识编辑 | 语言模型编辑方法与工具：操控模型对指定知识的记忆 |
| 4 | 数学推理 | 让大模型学会数学推理；快速蒸馏一个迷你 R1 |
| 5 | 模型水印 | 在模型生成内容中嵌入人类不可见的水印 |
| 6 | 越狱攻击 | 从攻击视角理解安全：越狱如何撬开大模型 |
| 7 | 大模型隐写 | 「看不见的墨水」：流畅回答中携带只有「自己人」能识别的信息 |
| 8 | 多模态模型 | 多模态大语言模型的理解与生成能力，是否通向 AGI |
| 9 | GUI 智能体 | AI Agent 替你点外卖、回消息、购物比价 |
| 10 | 智能体安全 | 大模型在开放智能体场景中的风险威胁意识 |
| 11 | RLHF 安全对齐 | 基于 PPO 的 RLHF 实验 |

## 国产化《大模型开发全流程》

联合华为昇腾推出，基于昇腾基础软硬件，覆盖 PPT/实验手册/视频，分初级/中级/高级，面向昇腾已支持模型与全新模型迁移调优。

## 关键概念清单

- 微调（Fine-tuning）/ 部署
- 提示学习（Prompting）/ 思维链（Chain-of-Thought, CoT）
- 知识编辑（Knowledge Editing）
- 数学推理 / 蒸馏（Distillation，mini-R1）
- 模型水印（Watermark）
- 越狱攻击（Jailbreak）
- 隐写术（Steganography）
- 多模态大语言模型（MLLM）
- GUI Agent / 智能体（Agent）
- 智能体安全（Agent Safety）
- RLHF（基于人类反馈的强化学习）/ PPO / 安全对齐（Alignment）

## 与本知识库的关联

本教程是主人（关注 AI 的前端工程师）系统学习 LLM 的主线资料之一，可作为 AI 主题页的结构骨架。
