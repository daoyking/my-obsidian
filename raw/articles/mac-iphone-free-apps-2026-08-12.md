## 1. Vorssaint — macOS 菜单栏万能工具箱

- **平台**：macOS 14+（仅 Apple Silicon）
- **价格**：完全免费，GPL v3 开源
- **GitHub**：https://github.com/vorssaint/vorssaint-utils
- **Stars**：3.3k+ | 最近更新：2026-08-10（v3.3.0）
- **安装**：`brew install --cask vorssaint/tap/vorssaint`

**一句话**：一个菜单栏图标，替代十几款付费 Mac App。

**核心功能**：
- 单 App 音量调节 + 突破 100% 增益 + 输出路由
- 实时系统监控（CPU/GPU/内存/温度/电池/网络）
- 窗口分屏与切换（⌘Tab 增强版带缩略图）
- 剪贴板历史记录
- 应用彻底卸载器
- Homebrew 管理器
- 共 60+ 功能，模块化按需启停

**亮点**：零账号、零遥测、零订阅，所有计算在本地。功能模块化，不用就不占资源。Apple Developer ID 签名 + 公证。

## 2. Mater — macOS 菜单栏番茄钟

- **平台**：macOS（原生 Swift）
- **价格**：完全免费，开源
- **GitHub**：https://github.com/jasonlong/mater
- **Stars**：939 commits | 最近更新：2026-08-05
- **安装**：`brew tap jasonlong/tap && brew install jasonlong/tap/mater`

**一句话**：极简番茄钟，住在菜单栏，不打扰你。

**核心功能**：
- 菜单栏图标实时倒计时
- 可拖拽时间标尺调整剩余时间
- 可配置工作/休息时长
- 键盘快捷键：空格暂停/继续，ESC 关闭
- 音效可关闭

**亮点**：macOS 原生 Swift 编写，体积极小，无后台进程，纯粹专注一件事。

## 3. Quill — macOS 本地会议录音转写

- **平台**：macOS 15+
- **价格**：完全免费，MIT 开源
- **GitHub**：https://github.com/digimata/quill
- **Stars**：3.7k+ | 活跃维护中

**一句话**：会议录音+转写全在本地，隐私零泄露。

**核心功能**：
- 麦克风 + 系统音频分轨录制
- 本地 on-device ML 转写，带时间戳和说话人识别
- 菜单栏极简 UI
- 零云端上传，隐私优先

**亮点**：Otter.ai / Fireflies 等竞品的免费开源替代品。所有音频不离开你的 Mac，无每分钟计费、无席位费。目前仅支持英文转写。

## 4. Loop — macOS 径向菜单窗口管理

- **平台**：macOS
- **价格**：完全免费，开源
- **GitHub**：https://github.com/MrKai77/Loop
- **安装**：`brew install --cask loop`

**一句话**：用径向菜单管理窗口，像玩游戏一样高效。

**核心功能**：
- 创新径向菜单：按住触发键 + 移动鼠标选择窗口布局
- 智能预览：操作前预览调整效果
- 半屏 / 三分 / 六分 / 角落 / 居中 / 跨屏
- 高度可定制：颜色、动画、触发键

**亮点**：比 Rectangle / Magnet 等传统窗口管理工具更直观，无需记忆快捷键。视觉化操作，学习成本几乎为零。

- **价格**：完全免费，MIT 开源
- **GitHub**：https://github.com/Ranchero-Software/NetNewsWire
- **Stars**：10.2k+ | 最近更新：2026-08-02
- **官网**：https://netnewswire.com

**一句话**：经典开源 RSS 阅读器，Mac + iPhone 双端同步。

**核心功能**：

**亮点**：10k+ Stars 的老牌项目，社区活跃，完全免费无内购。Mac 和 iPhone 双端覆盖，是追科技博客 / 新闻源的最佳免费工具。
